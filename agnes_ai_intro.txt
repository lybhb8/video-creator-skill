Agnes AI 简介

Agnes AI 是新加坡人工智能公司 Sapiens AI 推出的全模态大模型开放平台。自 2026 年 6 月起,Sapiens AI 将旗下文本、图片、视频三大类模型 API 无限期免费开放给全球开发者使用。

一、核心特点

免费开放:全部模型 API 免费调用,无需绑定银行卡,无 Token 额度上限,仅限制每分钟请求次数,普通开发者可以零成本完成各类 AI 应用开发。

全模态能力:平台同时提供文本、图片、视频三类模型。文本模型支持长篇上下文与深度思考;图片模型支持高质量图像生成与编辑;视频模型支持文生视频,可通过异步任务接口获取结果。

兼容 OpenAI 接口:Agnes AI 完全兼容 OpenAI 的 API 接口格式,开发者无需重写代码,只需将 baseURL 与密钥替换即可快速接入,极大降低迁移成本。

二、主要模型

文本模型:agnes-2.5-flash 为主力编码模型,拥有 512K 上下文窗口,支持工具调用与深度思考;agnes-2.0-flash 支持 1M 超长上下文,同样支持工具调用。

图片模型:agnes-image-2.1-flash 支持最高 4K 分辨率出图,并支持图片编辑功能。

视频模型:agnes-video-v2.0 支持文本生成视频,单次生成最长约 18 秒,通过异步任务轮询获取结果。

三、接入方式

Agnes AI 采用 OpenAI 兼容的 Chat Completions 协议,可通过多种方式接入:

直接调用:在 platform.agnes-ai.com 注册账号,创建以 sk 开头的 API Key,将请求地址指向 apihub.agnes-ai.com/v1 即可调用。

编程助手接入:通过开源代理工具 CC-Switch,将 Anthropic 协议的 Claude Code 和 OpenAI Responses 协议的 Codex 等编程助手的请求,翻译为 Agnes 兼容格式,实现免费调用 Agnes 模型。Opencode 支持原生 OpenAI 兼容供应商,直接在配置中新增 agnes 供应商即可。

四、使用场景

代码开发:作为 Claude Code、Opencode、Codex、Hermes 等编程助手的免费模型后端。
内容创作:利用多模态模型完成文案、图片、视频的批量生成。
学习研究:以零成本体验前沿大模型能力,适合个人开发者与教学场景。

五、注意事项

国内用户如果无法连接国际站,可使用 api.agnes-ai.cn 国内线路。API 密钥仅在创建时展示一次,务必立即保存。免费政策与模型能力可能随官方公告调整,建议以官网 agnes-ai.com 最新信息为准。
